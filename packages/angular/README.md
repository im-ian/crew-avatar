# @crew-avatar/angular

crew-avatar for Angular 17+, as a standalone component.

```sh
npm install @crew-avatar/angular
```

```ts
import { Avatar } from "@crew-avatar/angular";

@Component({
  imports: [Avatar],
  template: `<crew-avatar shape="full-moon" [state]="state" [size]="48" />`,
})
```

Options, states, theming and the full shape catalog: https://github.com/im-ian/crew-avatar#readme
