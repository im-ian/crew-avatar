# @crew-avatar/vue

crew-avatar for Vue 3.

```sh
npm install @crew-avatar/vue
```

```vue
<script setup>
import { Avatar } from "@crew-avatar/vue";
</script>

<template>
  <Avatar shape="ghostish" state="idle" :size="48" />
</template>
```

Options, states, theming and the full shape catalog: https://github.com/im-ian/crew-avatar#readme
