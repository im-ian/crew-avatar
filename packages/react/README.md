# @crew-avatar/react

crew-avatar for React 18+.

```sh
npm install @crew-avatar/react
```

```tsx
import { Avatar } from "@crew-avatar/react";

<Avatar shape="cup" state="working" size={48} seed={user.id} label={user.name} />;
```

Options, states, theming and the full shape catalog: https://github.com/im-ian/crew-avatar#readme
