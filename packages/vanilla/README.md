# @crew-avatar/vanilla

crew-avatar for plain HTML: a `<crew-avatar>` custom element and a drop-in `<script>` build.

```sh
npm install @crew-avatar/vanilla
```

```html
<script type="module" src="https://unpkg.com/@crew-avatar/vanilla/dist/crew-avatar.js"></script>

<crew-avatar shape="crown" color="#4da3ff" state="working" size="64"></crew-avatar>
```

Options, states, theming and the full shape catalog: https://github.com/im-ian/crew-avatar#readme
